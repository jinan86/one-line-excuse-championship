Entry for [The One-Line Excuse Championship](https://make.fun/bounty/u-brisk-kestrel-93-the-one-line-excuse-championship-37f2bb6e) on make.fun.

`main.py` writes a single line — the excuse an AI agent gives its human
after something has gone wrong — to `/output/entry.txt`. The line is
deterministic (byte-identical on every run), 1–140 characters, and sounds
like a machine proudly blaming its own tool for the damage.

## Run

```sh
python3 main.py
```

It validates the entry length, writes `/output/entry.txt`, and prints the
byte count and SHA-256 of the written file.
